# 30 — Checklist de revisão da BÍBLIA

Antes de aprovar uma versão:

### Produto
- [ ] objectivo compreensível;
- [ ] casos de uso;
- [ ] não-objectivos;
- [ ] experiência final.

### Domínio
- [ ] cada entidade tem propósito;
- [ ] uma autoridade por conceito;
- [ ] IDs e unicidade;
- [ ] estados;
- [ ] lifecycle;
- [ ] relações.

### Pipeline
- [ ] sequência completa;
- [ ] entradas/saídas;
- [ ] atalhos;
- [ ] falhas;
- [ ] cancelamento;
- [ ] idempotência.

### Reconhecimento
- [ ] matching;
- [ ] aliases;
- [ ] external identities;
- [ ] ambiguity;
- [ ] unknown;
- [ ] Review;
- [ ] não criação implícita.

### Sources
- [ ] Provider;
- [ ] Account;
- [ ] Source;
- [ ] ChannelSource;
- [ ] dedup;
- [ ] lifecycle.

### Policies
- [ ] precedência;
- [ ] snapshot;
- [ ] determinismo;
- [ ] desempates.

### Output
- [ ] ordering;
- [ ] groups;
- [ ] TV/Radio/VOD;
- [ ] M3U;
- [ ] atomicidade.

### Dispatcharr
- [ ] dry-run;
- [ ] ownership;
- [ ] partial failure;
- [ ] reconciliation;
- [ ] segurança.

### Operação
- [ ] first run;
- [ ] readiness;
- [ ] scheduler;
- [ ] restart;
- [ ] backup;
- [ ] restore;
- [ ] upgrade.

### Segurança
- [ ] secrets;
- [ ] SSRF;
- [ ] parser;
- [ ] auth;
- [ ] authz;
- [ ] audit.

### Verificação
- [ ] requisitos rastreáveis;
- [ ] testes;
- [ ] fixtures;
- [ ] E2E;
- [ ] performance;
- [ ] security.

### Documentação
- [ ] Roadmap deriva da BÍBLIA;
- [ ] AGENTS aponta para BÍBLIA;
- [ ] ADRs não contradizem BÍBLIA;
- [ ] código/documentação histórica não é usado como autoridade.
