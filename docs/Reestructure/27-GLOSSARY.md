# 27 — Glossário normativo

**CanonicalChannel:** identidade lógica canónica de um canal.

**Alias:** nome alternativo associado a um CanonicalChannel.

**ExternalIdentity:** identificador fornecido por uma origem/provider.

**IdentityRule:** regra explícita de reconhecimento.

**ReviewItem:** caso que requer decisão humana/administrativa para sair da incerteza.

**Provider:** ecossistema/fornecedor técnico.

**ProviderAccount:** conta concreta dentro de um Provider.

**Source:** origem que o operador quer processar.

**DiscoveryCandidate:** possibilidade descoberta antes de aceitação como Source.

**Playlist:** conjunto de entradas adquirido de uma Source.

**Stream:** entrada reproduzível de media.

**ChannelSource:** relação entre CanonicalChannel e Source.

**Observation:** evidência técnica observada durante um Run.

**Eligibility:** decisão sobre possibilidade de utilização baseada em policy + observations.

**SourcePriority:** preferência entre origens.

**SourceSelection:** escolha da stream concreta.

**OrderingList:** lista de posições configuradas.

**CanonicalGroup:** grupo de apresentação.

**GeneratedPlaylist:** output produzido pelo crawler.

**OwnershipRecord:** prova de que um recurso remoto é gerido pelo crawler.

**Run:** execução do sistema.

**RunSnapshot:** estado normativo capturado para uma execução.

**Readiness:** capacidade derivada de executar determinado modo operacional.

**Artifact:** ficheiro estruturado produzido para evidência/diagnóstico.

**Dry-run:** cálculo sem aplicação de efeitos remotos.
